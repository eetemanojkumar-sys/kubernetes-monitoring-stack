# Kubernetes Monitoring Stack with Prometheus, Grafana & Alertmanager

## Project Overview

This project implements a complete **Kubernetes Monitoring and Observability Stack** using **Prometheus, Grafana, Alertmanager, and the Prometheus Operator** deployed with the **kube-prometheus-stack Helm Chart**.

A custom Flask application was deployed on a Kubernetes cluster and monitored using Prometheus. Grafana dashboards were used to visualize cluster and application metrics, while custom Prometheus alert rules detected high CPU usage generated through load testing.

The monitoring stack was deployed and tested on a **Minikube Kubernetes Cluster running on an AWS EC2 Ubuntu instance**.

## Monitoring Workflow

The monitoring pipeline follows this workflow:

```text
Application
      |
      v
Kubernetes Cluster
      |
      v
Prometheus Scrapes Metrics
      |
      +----------------------+
      |                      |
      v                      v
Grafana Dashboard      Alert Rules
                              |
                              v
                       Alertmanager
```

Prometheus continuously collects metrics from Kubernetes nodes, pods, containers, and the custom application.

Grafana visualizes the collected metrics using interactive dashboards.

Prometheus evaluates custom alert rules and forwards firing alerts to Alertmanager.

## Custom Prometheus Alert

A custom alert was created to detect high CPU utilization.

```yaml
alert: MonitoringDemoHighCPU

expr: |
  sum(rate(container_cpu_usage_seconds_total{
  namespace="default",
  pod=~"monitoring-demo-.*"
  }[1m])) > 0.2

for: 1m

labels:
  severity: warning

annotations:
  summary: Monitoring demo CPU usage is high
```

## Load Testing

CPU load was generated using a BusyBox container.

```bash
kubectl run load-generator \
--rm -it \
--image=busybox \
--restart=Never -- sh
```

Generate continuous load:

```bash
while true
do
wget -q -O- http://monitoring-demo:5000/work
done
```

The generated workload successfully triggered the custom Prometheus alert.

## Helm Deployment

Add Prometheus Community Repository

```bash
helm repo add prometheus-community https://prometheus-community.github.io/helm-charts

helm repo update
```

Create Monitoring Namespace

```bash
kubectl create namespace monitoring
```

Install Monitoring Stack

```bash
helm install monitoring prometheus-community/kube-prometheus-stack \
--namespace monitoring
```

Verify Installation

```bash
kubectl get pods -n monitoring
```
